# LogAI Platform

AI-powered log analysis with web app, mobile app (iOS & Android), and ML inference engine.

## Structure
- `web-app/`         React + TypeScript + Vite
- `mobile-app/`      React Native (iOS & Android)
- `backend/api/`     Node.js + Express API
- `backend/ml-service/`  Python + FastAPI ML service
- `shared/`          Shared types & utilities
- `infra/`           Docker, Terraform
- `docs/`            Architecture & API docs

## Quick Start
```bash
docker compose up
```
See docs/ for per-service setup.
